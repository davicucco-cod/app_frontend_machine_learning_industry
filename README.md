# Monitor de Confiabilidade Industrial (Predictive Maintenance App)

> **Status:**  Projeto de Estudo & Aprendizado (Em Desenvolvimento)

Este repositório documenta minha jornada de aprendizado em **Data Science aplicado à Indústria 4.0**.
O objetivo aqui não foi criar um produto comercial final, mas sim dominar o **ciclo completo de desenvolvimento (End-to-End)**: da limpeza dos dados brutos até o deploy de uma aplicação funcional.

##  Objetivos de Aprendizado Alcançados
* **Pipeline de Dados:** Tratamento de dados desbalanceados com SMOTE.
* **Modelagem:** Treinamento e validação de algoritmos (Random Forest).
* **Engenharia de Software:** Criação de interface front-end com Streamlit.
* **Deploy:** Disponibilização do modelo via web (Ngrok).

##  Próximos Passos (Roadmap de Estudos)
Estou ativamente aprofundando meus conhecimentos para evoluir este projeto:
* Implementar métricas de negócio (Custo de Falha vs. Custo de Manutenção).
* Testar arquiteturas de Deep Learning (Redes Neurais) para comparação.
* Melhorar a persistência de dados com Banco SQL.
* Containerizar a aplicação com Docker.
